# Épure Botanique — Atelier de Soins

A luxury, clean botanical hair and skincare e-commerce website inspired by French apothecary aesthetic with zero external frameworks or dependencies.

## Features

- **Botanical Care Catalog**: Curated restorative hair treatments, scalp elixirs, barrier creams, facial oils, and body balms.
- **Category Filter**: Seamless instant filtering between *All Care*, *Hair Care*, *Skin Care*, and *Body Care*.
- **Interactive Care Bag**: Persistent client-side cart drawer with item counter, quantity controls, dynamic price computation, and removal.
- **WhatsApp Direct Checkout**: One-click order placement formatting all selected items, quantities, and totals directly to WhatsApp.
- **Trilingual Localization (EN / FR / AR)**: Full instant language switching with automatic Right-to-Left (RTL) directional layout support for Arabic.
- **Single Source of Truth**: Dynamic server-side rendering of product cards, structured SEO data (JSON-LD), and FAQs from JSON files.
- **Lightweight Backend**: Built-in zero-dependency Python server with rate-limiting, double opt-in newsletter API, and privacy-respecting analytics.

## Running the Store

Run from PowerShell or terminal:

```powershell
cd D:\code\webProject\careProject
python server.py
```

Then visit: [http://localhost:4175](http://localhost:4175)
